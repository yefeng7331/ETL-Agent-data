# 流程三：运行质量、发布与回滚

状态：文档已验收；功能与运行验收另见实施状态。

权威规则见 [MVP_SPEC](MVP_SPEC.md)；前端连续操作见 [前端全链路流程](FRONTEND_END_TO_END_FLOW.md)，后端连续交接见 [后端全链路流程](BACKEND_END_TO_END_FLOW.md)。本流程接收[审批流程](FLOW_02_APPROVAL_COMMIT.md)创建的 `ExecutionRun` 与 Outbox 事实。页面只发起有权限的操作并展示服务端状态，数据搬运由 SeaTunnel 完成。

| 步骤 | Vue 页面操作与可见状态 | FastAPI／Celery／SeaTunnel 职责与交接 | 失败反馈 |
| --- | --- | --- | --- |
| 1. 受管启动 | 运行中心显示已提交、待执行、运行中及作业 ID；自动定期读取服务端状态、标明更新时间并支持手动刷新，离开后可重进同一运行。 | Celery Worker 消费受管命令并验签，仅在授权执行时从 Vault KV v2 物化 Secret，再提交 SeaTunnel；控制面记录作业 ID、状态与指标。 | 验签、凭据获取或作业提交失败时显示失败原因及实际状态；断线时标明结果待确认，恢复后重读记录。 |
| 2. 增量与分流 | 页面展示读写量、吞吐、日志、有效／拒绝行数和错误码分布；行级样例仅供获授权角色查看或下载，且须脱敏。 | SeaTunnel 依冻结水位把订单/用户增量搬运到 Doris 暂存区；Doris 关联暂存与历史数据，生成完整影子宽表，用户变更影响全部历史订单。仅行级格式/值异常按冻结阈值分流。 | 作业、暂存或重建异常时保留诊断事实；不完整影子表不得作为正式版本展示。 |
| 3. 监督与质量结论 | 运行中心展示预算、阈值命中、硬中断或质量通过及可解释诊断；有运行查看权限者可见汇总，行级样例仍受授权与脱敏控制。 | 后端对照冻结预算、质量阈值及完整性报告判定；只有可容忍行级异常在阈值内才可继续。安全暴露、Schema、主键、映射和完整性错误直接阻断。 | 硬中断或质量失败时记录快照、原因与证据；页面明确显示不可发布，不由前端自行判定达标。 |
| 4. 原子发布 | 页面分别显示质量通过、发布中、已发布或发布失败及前后版本；只呈现后端确认的正式结果。 | 本轮 Commit 授权内，质量与完整性均通过后，后端自动协调 Doris 影子表原子 Swap，核实并记录正式结果；保留当前版与紧邻上一版。 | 发布失败时显示目标端实际正式表状态及回滚路径；不得将仅有合格报告显示为已发布。 |
| 5. 受管回滚 | 具备权限的 Operator 先预览当前版、目标版和影响，填写原因并显式确认；页面显示回滚中、已回滚或失败及实际版本。 | 后端核验权限和目标，无须新双人审批：发布前清理未发布影子表；发布后使用紧邻上一正式版本反向 Swap。将操作及结果写入 Evidence Ledger。 | 权限不足、目标不可用或回滚失败时显示原因和实际正式版本；断线后重读回滚记录，前端不直接清表或执行 Swap。 |

运行中心应区分运行中、硬中断、质量失败、待发布、已发布、回滚中、已回滚及回滚失败。Operator 受管中断时，后端停止作业、阻止发布并清理未发布暂存和影子结果；已发布内容走受管回滚。发布与回滚按 Pipeline 串行，预览绑定操作 ID 与所见正式版，变化时旧预览失效。成功发布后才推进已发布水位；发布后回滚成功须恢复上一正式版水位、失效旧准备单，后续新 Prepare 与双审批重放。软删订单从当前宽表移除，软删用户保留订单事实、清空用户维度字段并标记删除。脱敏样例查看与下载在数量上限及授权规则批准前保持阻断。每轮保留 Preparation、ExecutionRun、质量报告和可校验的审计证据；不在界面或日志暴露凭据。状态由后端提供，页面采用自动定期刷新并允许手动刷新；更旧版本自动清理须待保留期、存储预算及审批政策确认。接口交接见 [接口契约](API_CONTRACT.md)。
